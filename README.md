# Urtikaria Tagebuch – Version 2.8

- Eingaben unter „Heute“ werden nach Auswahl automatisch gespeichert, sobald Quaddeln und Juckreiz erfasst sind.
- Der manuelle Speichern-Button bleibt als zusätzliche Möglichkeit erhalten und verwendet eine vereinfachte Klick-Logik.
- Abschnitt 4 heißt jetzt „Medikation“. Neue Präparate werden über „+ Neues Präparat“ bei Bedarf eingeblendet.
- „Ungewöhnliches Essen“ wurde in „Ernährung“ umbenannt; der Info-Hinweis bleibt erhalten.
- „Kälte“ wurde als Standard-Auslöser ergänzt.
- Eigene Auslöser bleiben oberhalb von „Anderer Auslöser“ sichtbar und löschbar.
- Im Kalender erklärt die Legende nun zusätzlich „0–6 = Tages-UAS“.
- Verlauf: Woche/Monat, Wischgesten mit Rückgängig sowie Arzttermine bleiben erhalten.
